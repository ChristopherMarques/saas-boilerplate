# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Next.js (App Router), Tailwind CSS v4, React 19, Shadcn UI, React Aria, Vitest, PostgreSQL (Prisma), Posthog + Clarity + GA4.

## Users

Developers, technical founders, and indie hackers who want to launch a SaaS product quickly without reinventing the wheel for auth, payments, testing, and analytics.

## Product Purpose

A high-performance SaaS boilerplate that provides out-of-the-box infrastructure. Success means a developer can start writing core product logic on day 1 instead of configuring tooling.

## Positioning

It uses a feature-sliced modular architecture (Features, Shared, App) unlike flat boilerplates, and includes built-in i18n from day 1, making it enterprise-ready out of the gate.

## Operating Context

Developers will use this via CLI to bootstrap new projects, deploy on Vercel/AWS, and manage their databases locally or via managed services.

## Capabilities and Constraints

- Strictly adheres to React 19 rules (no manual scripts in client components).
- Requires high testing coverage (Vitest).
- Uses Mintlify for documentation.
- Stripe and Cakto are both pre-configured for optional use.
- The project implements a forced dark theme.

## Brand Commitments

Uses "Impeccable" UI aesthetics: aggressive and modern dark mode, glassmorphism, noise overlays, high-contrast primary colors (#D90429), and bold typography.

## Evidence on Hand

Working feature-sliced codebase with a functional Next.js 15+ environment, Github Actions ready, comprehensive ESLint/Prettier/Husky hooks, Mintlify docs scaffold.

## Product Principles

- **Developer Experience First:** Tooling must be invisible, fast, and robust.
- **Strict Quality:** 100% type safety and testing as a default.
- **Premium Aesthetics:** Not just functional, but aggressively modern and visually striking.
