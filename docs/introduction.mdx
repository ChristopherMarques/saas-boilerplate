# SaaS Boilerplate

Bem-vindo ao melhor SaaS Boilerplate pronto para produção, construído com Next.js 16 (App Router), Supabase, Better Auth e Stripe/Cakto. 

Essa arquitetura foi testada em batalha ao longo de 1 ano de desenvolvimento real de SaaS, abstraindo toda a configuração tediosa de autenticação, internacionalização, pagamentos e métricas.

## O que está incluído?

- **Framework:** Next.js 16 (App Router) com React 19 e React Compiler
- **Banco de Dados:** Supabase com Row-Level Security (RLS)
- **Autenticação:** Better Auth (Google OAuth) com ponte JWT para Supabase
- **Pagamentos:** Stripe & Cakto (Webhooks pré-configurados)
- **Estilização:** Tailwind CSS v4, shadcn/ui, React Aria
- **Estado:** React Query (com persistência offline) e Zustand
- **i18n:** Inglês e Português nativos
- **Testes:** Vitest & React Testing Library
- **Métricas:** PostHog, Microsoft Clarity, e ponte GA4

## Filosofia

O objetivo deste boilerplate é fornecer uma fundação escalável, pronta para Micro-Frontends (MFE), que você possa usar para iniciar projetos muito mais rápido, sem sacrificar a qualidade do código. Nós seguimos princípios SOLID e mantemos uma clara separação de responsabilidades usando a estrutura de diretórios `features/` e `shared/`.
