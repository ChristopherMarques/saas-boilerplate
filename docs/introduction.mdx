# SaaS Boilerplate

Welcome to the ultimate production-ready SaaS Boilerplate, built with Next.js 16 (App Router), Supabase, Better Auth, and Stripe/Cakto. 

This architecture has been battle-tested over 1 year of real-world SaaS development, abstracting away the tedious setup of authentication, internationalization, payments, and analytics.

## What's included?

- **Framework:** Next.js 16 (App Router) with React 19 and React Compiler
- **Database:** Supabase with Row-Level Security (RLS)
- **Auth:** Better Auth (Google OAuth) with a Supabase JWT bridge
- **Payments:** Stripe & Cakto (Webhooks pre-configured)
- **Styling:** Tailwind CSS v4, shadcn/ui, React Aria
- **State:** React Query (with offline persistence) and Zustand
- **i18n:** English & Portuguese out of the box
- **Testing:** Vitest & React Testing Library
- **Analytics:** PostHog, Microsoft Clarity, and GA4 bridge

## Philosophy

The goal of this boilerplate is to provide a scalable, MFE-ready foundation that you can use to start projects faster without sacrificing code quality. We follow SOLID principles and maintain a clear separation of concerns using a `features/` and `shared/` directory structure.
