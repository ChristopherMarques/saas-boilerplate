## Pré-requisitos

- Node.js 18+ (Node 20 recomendado)
- `pnpm` (gerenciador de pacotes padrão)
- Um projeto Supabase
- Um projeto no Google Cloud Console (para OAuth)

## Instruções de Instalação

1. **Instalar dependências:**
   ```bash
   pnpm install
   ```

2. **Variáveis de Ambiente:**
   Copie o `.env.example` para `.env.local` e preencha suas credenciais.

   ```bash
   cp .env.example .env.local
   ```

3. **Migração do Banco de Dados:**
   Execute a migração inicial contra a sua instância do Supabase para criar as tabelas necessárias.
   Você pode copiar o conteúdo de `supabase/migrations/0000_initial.sql` diretamente para o editor SQL do Supabase.

4. **Rodar o Servidor de Desenvolvimento:**
   ```bash
   pnpm run dev
   ```

## Fluxo de Desenvolvimento

Este boilerplate está configurado com controles rigorosos de qualidade:
- **Husky & Lint-Staged:** Roda Prettier e ESLint em todos os arquivos em staged antes de cada commit.
- **Type Checking:** Roda `tsc --noEmit` antes dos commits para garantir zero erros de tipagem.
- **Testes Unitários:** Roda o Vitest nos arquivos em staged.

Você pode rodá-los manualmente usando:
```bash
pnpm run lint:fix
pnpm run type-check
pnpm run test
```
